# v2.8.0

- Add an opt-in image preprocessing switch for plugin-level image caption requests.
- Limit the derived vision input to a configurable longest edge and JPEG quality, defaulting to 1280 and 85.
- Preserve original media, avoid upscaling small images, and keep untouched PNG/WebP payloads with their real MIME types.
- Add Pillow as an explicit plugin dependency and cover preprocessing behavior with unit tests.
